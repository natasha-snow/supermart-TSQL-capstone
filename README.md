<h1>Introduction to T-SQL Capstone Project</h1> 
<h3>Learning Outcomes </h3> 
<h4>By completing this capstone project, you will demonstrate your ability to:</h4> 
    <ul>
    <li>Create and modify database tables using DDL statements. </li>  
    <li>Insert, update and delete records using DML statements. </li>  
    <li>Retrieve data using the SELECT statement. </li>  
    <li>Apply column aliases, concatenation and COALESCE(). </li>  
    <li>Filter records using WHERE, DISTINCT, LIKE, IN, BETWEEN, IS NULL, AND, OR, and <>. </li>  
    <li>Retrieve related data using SQL joins. </li>  
    <li>Sort, group and aggregate data. </li>  
    <li>Use SQL date and string functions. </li>  
    <li>Create and use subqueries. </li>  
    <li>Create a view. </li>  
    <li>Create a Common Table Expression (CTE). </li>  
    <li>Create and execute a stored procedure. </li>  
    <li>Use IF...ELSE logic. </li>  
    <li>Implement transactions. </li>  
    <li>Handle errors using TRY...CATCH. </li>
    </ul>
